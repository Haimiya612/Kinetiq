# Kinetiq Design System

## Product personality

Hybrid: premium cinematic presentation with enthusiast-level capabilities underneath.

The default experience should feel calm, intentional, and easy to navigate. Advanced controls should be discoverable without overwhelming the primary viewing experience.

## Theme strategy

Adaptive light and dark themes:

- Follow system preference by default where supported.
- Offer an explicit user override: System / Light / Dark.
- Maintain consistent semantic colour roles across themes.
- Avoid using colour alone to communicate status.
- Validate contrast and legibility at typical Quest viewing distances.

## Visual direction

- Cinematic surfaces with restrained depth and clear hierarchy.
- High-quality artwork presentation without excessive motion.
- Large, comfortable hit targets for controllers and hands.
- Consistent focus states for gaze/controller navigation.
- Motion should be purposeful, brief, and reduceable.
- Responsive layouts for headset, phone, and tablet-sized surfaces where relevant.

## Interaction principles

- Primary actions remain obvious.
- Advanced playback and source controls are available but not permanently intrusive.
- Every asynchronous operation has loading, success, empty, and failure states.
- Back navigation and focus restoration must be predictable.
- Respect reduced-motion and accessibility preferences where available.

## Initial design tokens

Exact numeric values will be established during Phase 1 after testing in-headset. Avoid hard-coding theme-specific colours in feature screens; consume semantic tokens from the design system.

## Product identity

- Kinetiq Player — **Motion. Media. Modular.**
