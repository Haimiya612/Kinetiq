# Kinetiq

**Fluid streaming, limitless extensions.**

Kinetiq is a modular media platform designed for Meta Quest, combining an immersive media player, an extensible source engine, and a personal media library.

## Product family

- **Kinetiq** — the platform and ecosystem.
- **Kinetiq Player** — the application. *Motion. Media. Modular.*
- **Kinetiq Engine** — the source, discovery, metadata, and extension framework. *Your streams, your modules, your rules.*

## Product principles

1. Premium presentation with enthusiast-level control.
2. Adaptive light and dark themes.
3. Local-first personal data; no mandatory account.
4. Modular source integrations behind stable adapters.
5. Quest-native comfort and interaction.
6. Secure-by-default extension execution.
7. Respect for source authorisation, copyright, DRM, and access controls.

## Current status

**Phase:** 0 — Product and engineering foundation  
**Target device:** Meta Quest 3  
**Initial platform:** Android / Horizon OS  
**Proposed stack:** Kotlin, Jetpack Compose, AndroidX Media3, and Quest spatial APIs where appropriate.

This repository currently defines product and engineering foundations. It does not yet contain an implemented player, module runtime, or streaming engine.
